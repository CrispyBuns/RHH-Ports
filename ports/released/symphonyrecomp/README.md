# Castlevania: Symphony of the Night Recomp — KNULLI / RG35XX-H

This directory contains the PortMaster/KNULLI wrapper for SymphonyRecomp.

## Status

The launcher and PortMaster metadata are prepared for the RG35XX-H's ARM64 environment. The actual `sotn` ARM64 executable still needs to be produced from the SymphonyRecomp source; copyrighted game data is intentionally not included.

## Required files

Place the ARM64 SymphonyRecomp build in `symphonyrecomp/` and make `sotn` executable.

The required Symphony of the Night source/game data must be obtained from a legally owned North American NTSC PSX copy according to the upstream project's instructions.

## Target

- Device: Anbernic RG35XX-H
- OS: KNULLI
- Architecture: AArch64 / ARM64
- Launcher: PortMaster
