# Phase Distorter — RG35XX-H / KNULLI

This is an experimental ARM64 PortMaster build of [Phase Distorter](https://github.com/TheRunaway5/Phase-Distorter).

## First launch

Launch **Phase Distorter** and use its setup window to import your own supported retail ROM:

- EarthBound (US)
- Mother 2 (Japan)

ROM files and imported asset packs are not distributed with this port. Keep your ROM backed up and do not copy copyrighted ROMs into this repository.

## Status

This is an initial porting scaffold. It requires device testing before it can be described as working. The upstream frontend uses SDL2 and desktop OpenGL; the RG35XX-H/KNULLI graphics context, runtime libraries, controller navigation, and asset import paths must be verified on-device.
